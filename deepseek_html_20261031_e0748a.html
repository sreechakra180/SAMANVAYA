Abstract. This book specifies the trust subsystem, performance engineering, and test plan for an anonymous community scam-reporting platform. The engine does not count reports — it counts independent sources. Reporter identity is reduced to keyed pseudonymous fingerprints, reports are collapsed into source clusters, coordinated campaigns are detected and merged into a single evidence unit, and evidence mass is aggregated through a skeptical Beta-Binomial posterior before a deterministic state machine assigns one of the four official verdicts. Two invariants are enforced outside the arithmetic: a disputed identifier can never be KNOWN_SCAM, and an allowlisted business can never be anything other than VERIFIED_BUSINESS. Part 2 covers lookup latency, ingestion, time windows, alerts and benchmark methodology. Parts 3 and 4 reconcile thresholds and provide a reproducible synthetic generator plus contract/privacy/licence/load test plans.

1.2 Privacy-preserving identity handling (non-negotiable)

K_id  := 32-byte secret from TRUST_HMAC_KEY env   (never git, never logs)
rid_fp = HMAC-SHA256(K_id, "rid:" || reporter_id).hex()[:32]
net_fp = HMAC-SHA256(K_id, "net:" || ip_prefix).hex()[:16]
  1. reporter_id / ip_prefix written once into an identity_vault table and then discarded from the request object. No other table references them.
  2. Log formatter carries a denylist replacing reporter_id, ip_prefix, note, contact_email, claimant_name with [redacted] before any sink (stdout, file, Sentry). Unit-tested.
  3. GET /lookup evidence[] never contains rid_fp, net_fp, note, exact coordinates — only occurred_at, channel, scam_type, pincode.
  4. TRUST_HMAC_KEY versioned (K_id_v1). Rotation breaks cross-period linkage but preserves aggregates.
  5. Reporter reliability stored as (n_good, n_bad) keyed by rid_fp — no free text, no record of what they reported.

3.3 Independence — the core defence

def source_clusters(reports):
    uf = UnionFind(reports)
    for a, b in pairs(sorted(reports, key=report_id)):
        if a.rid_fp == b.rid_fp:
            uf.union(a, b)
        elif a.net_fp == b.net_fp and |a.reported_at − b.reported_at| ≤ 6h:
            uf.union(a, b)
    return uf.groups()
v_k = max_{i ∈ cluster k} w_i # duplicates add nothing E = Σ_k v_k

Implements: "One person reporting many times is still one person" and "Many reports from the same internet connection within a short time count as one person."

Design note on net_fp. A /24 window is coarse. Two genuine victims on the same ISP block within 6 h will merge, under-counting evidence. We accept that: under-counting is a false negative on a scam; over-counting is a false positive on an innocent business. The brief prioritises the second.

3.4 Coordination collapse

For G = clusters reporting within 120 min:
  γ_note = fraction with a Jaccard ≥ 0.70 partner in G
  γ_time = fraction in the 120-min peak window
  γ_age  = fraction of reporters with < 3 prior reports
  γ      = 0.55·γ_note + 0.30·γ_time + 0.15·γ_age
  CAMPAIGN iff γ_note ≥ 0.60 ∧ γ ≥ 0.70
  v_G = max_{k∈G} v_k · min(1, 1 + 0.1·log2|G|)
  E   = Σ_{k∉G} v_k + v_G

γ_note ≥ 0.60 is a hard gate. A genuine wave of 40 people writing in their own words fails it and is not collapsed — exactly the discriminator the brief asks for.

5.4 Hard invariants (asserted in code, tested in CI)

  1. DISPUTED ⇒ verdict ≠ KNOWN_SCAM. Enforced after scoring, as a final if, not a threshold. Cannot be outvoted by volume.
  2. KNOWN_SCAM ⇒ c ≥ 3. The three-reporter rule is the privacy/display floor and a necessary but not sufficient condition. Also needs c≥5 ∧ S≥0.75.
  3. Allowlist ⇒ VERIFIED_BUSINESS. Checked before scoring.
  4. display_value masked whenever distinct_reporters < 3 — 98XXXXX210, r***@okaxis, sbi***.in/..., HD***.
  5. Wording. "Reported by N people near you". "scammer"/"fraud" banned by lint.

Phase 6 — Alert Poisoning

6.1 Trusted-reports filter

w_i ≥ 0.40                        # junk/templated/back-dated excluded
cluster k not in a collapsed CAMPAIGN
occurred_at inside the window being evaluated (24 h or 7 d)
pincode ∈ accepted area table

Counts are distinct source clusters, never raw reports.

6.2 Exact PRD conditions

baseline_per_day = trusted clusters in [now-8d, now-1d) / 7
SPIKE   iff  n24 ≥ 5  ∧  n24 ≥ 2·baseline_per_day
             ∧  ≥3 distinct net_fp  (hardening gate)
NEW_TYPE iff  ∃ scam_type with ≥3 trusted clusters in [now-24h, now)
              ∧  absent from pincode in [now-30d, now-24h)

The ≥3 distinct net_fp clause is a second independent gate: a single actor holding 30 accounts on one Wi-Fi cannot fire a SPIKE even if clustering is bypassed.

6.4 Honest weakness — paraphrase attack

An adversary with 15+ clean networks, 15 aged accounts, genuinely reworded notes, good scam-type specificity will reach S≈0.78 and be labelled KNOWN_SCAM. We say so. Mitigations:

  1. c ≥ 5 gate — small coordinated sets can't do it alone.
  2. Hysteresis — sustained, not one-shot.
  3. Reputation ρ — accounts never once corroborated sit at the mean; never quickly exceed 1.0.
  4. Challenge veto — guaranteed path to SUSPICIOUS-only. The real backstop: cost of a successful paraphrase attack is a disputed label, not a permanent one.
  5. Optional cached embedding bucket — off by default; never decision authority.

8.3 Deterministic pseudocode

def assess(indicator, now):
    if indicator in ALLOWLIST: return VERIFIED_BUSINESS
    reports = sorted(db.reports(indicator), key=rid)
    if not reports: return NO_REPORTS
    cl = source_clusters(reports)
    sim = minhash_lsh([r.note for r in reports])
    for r in reports:
        r.w = clip(note_q(r,sim)*type_q(r)*evidence_q(r)*temporal_q(r,now)
                   *reputation(r.rid_fp), 0, 1)
    v = {k: max(r.w for r in g) for k, g in cl.items()}
    G = detect_campaign(cl, reports, sim, now) if len(cl) >= 4 else None
    if G:
        v_G = max(v[k] for k in G) * min(1.0, 1 + 0.1*log2(len(G)))
        E = sum(val for k,val in v.items() if k not in G) + v_G
    else:
        E = sum(v.values())
    D = dispute_mass(indicator, now)
    S = (0.5 + E) / (2.0 + E + D)
    c = len(cl)
    state = classify(c, S, indicator, now)
    verdict = "KNOWN_SCAM" if state == HIGH_CONFIDENCE else "SUSPICIOUS"
    if indicator.challenged or state == DISPUTED: verdict = "SUSPICIOUS"
    if c < 3:                                      verdict = "SUSPICIOUS"
    if indicator in ALLOWLIST:                     verdict = "VERIFIED_BUSINESS"
    return TrustAssessment(verdict=verdict, state=state, score=round(S,6),
        E=round(E,6), report_count=len(reports), distinct_reporters=c,
        first_seen=min(...), last_seen=max(...), display_value=mask(indicator,c),
        evidence=[...10 most recent...])

Determinism: sorted iteration, fixed MinHash seed, explicit now, no LLM, no wall clock inside scoring.

8.7 Pitch (60 s)

We never count reports — we count independent sources.

Every report is fingerprinted with a keyed hash so we recognise "same person" without knowing them. Reports from the same person, or the same network inside a six-hour window, collapse into one. One person six times = one person. Twenty-two accounts on one Wi-Fi = one person.

Each remaining piece gets a weight from 0 to 1: a written description counts more than copy-paste; a screenshot adds 8 %, not 80 %; a report from two months ago counts less than one from an hour ago; a brand-new user counts exactly the same as an established one.

Then we look for campaigns: many "independent" accounts writing near-identical notes in the same two hours. When we find that, forty friends become one witness. Genuine victims write in their own words, so they never collapse.

We combine with a Beta-Binomial starting from a skeptical prior. KNOWN_SCAM needs five independent sources, a score above 0.75, and no active dispute. Three reporters is only where we stop hiding the number — never proof.

If a business disputes, that's a hard switch, not a vote. A disputed identifier can never be KNOWN_SCAM.

Every verdict is reproducible — same reports, same verdict. We can show the arithmetic.

A. Lookup Architecture

A.1 The core decision

The naive approach aggregates the reports table per lookup — cost is O(reports), grows without bound. Wrong shape.

Precompute the verdict. At write time the trust engine computes a full TrustAssessment per indicator and stores it as one row in indicators. GET /lookup is then:

  1. Canonicalise (pure CPU, no I/O).
  2. One unique-index probe.
  3. Serialise.

Cost is O(1) in reports. Redis, pooling, serialisation are optimisations on top. None is load-bearing.

A.2 Latency budget

Stagep50p95Notes
Client → edge (keep-alive)20 ms60 msOutside our control
Edge → app (same region)1 ms3 ms—
Middleware (parse, licence, RL)0.5 ms2 msLicence cached verify+compare
Canonicalise0.05 ms0.3 msCompiled regex

Network dominates. Internal budget leaves ~480 ms headroom at p95. We don't chase microseconds; we prevent spikes (§A.9).

A.3 Canonicalisation

Shared function, compiled once, used at ingest and lookup — divergence is the classic "not found" bug.

PHONE_MOBILE   = re.compile(r"^\+91[6-9]\d{9}$")
PHONE_TOLLFREE = re.compile(r"^\+91(1800|1860)\d{4,7}$")
PHONE_HELPLINE = re.compile(r"^\+911\d{3}$")

def canonicalise(kind, raw):
    if kind == "phone":
        s = re.sub(r"[ \-().]", "", raw.strip())
        if s.startswith("00"): s = "+" + s[2:]
        if s.startswith("0") and len(s)==11:  s = "+91" + s[1:]
        if s.startswith("91") and len(s)==12: s = "+" + s
        if not s.startswith("+"):             s = "+91" + s
        return s if (PHONE_MOBILE.match(s) or PHONE_TOLLFREE.match(s)
                     or PHONE_HELPLINE.match(s)) else None
    if kind == "upi":
        s = raw.strip().lower().replace(" ", "")
        return s if UPI_RE.match(s) else None
    if kind == "url":
        s = raw.strip().lower()
        s = re.sub(r"^http://", "https://", s)
        s = re.sub(r"^https://www\.", "https://", s)
        s = s.split("?", 1)[0].rstrip("/")
        return s if URL_RE.match(s) else None
    if kind == "sender_id":
        s = raw.strip().upper()
        s = re.sub(r"^[A-Z]{2}-?", "", s)
        return s if SENDER_RE.match(s) else None

If None, return 400 before any datastore.

    WHERE trust_state = 1;

Partial indexes keep the trusted subset resident in shared_buffers and remove filter steps. INCLUDE makes the evidence query index-only. Selectivity: (kind, canonical) unique → planner has no risk. No query-planning uncertainty on the hot query, which removes a common p99 source.

A.6 DB-only vs cache

Approachp50 internalStrengthsWeaknesses
DB only~2 msOne source of truthPool consumption, repeated work
Redis in front~0.5 ms~90 % DB round-trips removedInvalidation protocol
L1 + Redis~0.05 msFastest for top-NMemory, staleness

Selected: Redis as L2, optional L1 for top 1 000. DB-only meets the target by itself; Redis protects the connection pool as load grows. At 3 000 rps with DB-only, pool contention starts producing tail latency the p50 hides.

Cache key: "lk:v1:" + base64url(kind) + ":" + sha256(canonical)[:20]; value is finished serialised bytes, so hit path does zero work. TTL 300 s + jitter ±30 s.

A.7 Invalidation

  1. indicators.version increments on recompute.
  2. Write-through: trust worker SETs new body in same TX.
  3. Delete-on-write fallback if SET fails.
  4. TTL 300 s bounds staleness.
  5. Dispute is synchronous: POST /challenges writes challenged=true and SET/DEL before returning 201.

A.8 Connection pooling

Pgbouncer (transaction mode) in front of Postgres. connections = (cpu_cores × 2) + effective_spindles — 4 vCPU SSD → 9. max_connections = pools×10 + 5.

Postgres is process-per-connection; beyond 2×cores active connections, context switching and lock contention raise latency. Little's Law: λ=300 rps, W=2 ms → L=0.6 avg, L≈3 at p99. Pool of 9 has 3× headroom.

A.9 Tail latency

Degradation ladder

  1. Redis down → DB only, no user-visible change.
  2. Replica lagging → reads go to primary.
  3. DB saturated → statement_timeout → 503 with Retry-After.
  4. Everything down → /health OK, /lookup 503. Licence checked before datastore, so expired still returns 403 LICENSE_EXPIRED.

The rule: fail fast, honest, ordered.

  • Flat shape; evidence ≤ 10; dates pre-formatted at write time.
  • Pre-serialised on hit path.
  • No gzip below 1 KB.

A.12 Lookup pseudocode

async def lookup(kind_raw, value_raw):
    kind = KIND_MAP.get(kind_raw)
    if kind is None: return 400("unknown identifier_type")
    canonical = canonicalise(kind, value_raw)
    if canonical is None: return 400("invalid identifier_value")

    key = cache_key(kind, canonical)
    if (hit := l1.get(key)) is not None: return raw_json(hit)
    try: hit = await redis.get(key, timeout_ms=20)
    except (RedisTimeout, RedisUnavailable): hit = None
    if hit is not None:
        l1.set(key, hit, ttl=30); return raw_json(hit)

    try: row = await db.fetchrow(LOOKUP_SQL, kind, canonical, timeout_ms=200)
    except StatementTimeout:
        return json_error(503, "lookup timeout", retry_after=1)

    body = encode(row) if row else encode(NO_REPORTS_BODY(kind, canonical))
    await redis.set(key, body, ex=300 if row else 60)
    l1.set(key, body, ttl=30)
    return raw_json(body)

B.3 Asynchronous work

job = {indicator_id, reason, enqueued_at}. Worker recomputes from stored reports. Pure function of stored reports → lost job is harmless.

B.4 Idempotency

INSERT INTO reports (...) ON CONFLICT (report_id) DO NOTHING RETURNING report_id;

Row → first insert → 201, enqueue. Null → replay → 201, no enqueue. merged:true computed from whether the indicator row already existed.

B.6 Bounded queues

INGEST_MAX_PENDING        = 10_000
INGEST_SHED_THRESHOLD     = 0.80
INGEST_WORKER_CONCURRENCY = 4
INGEST_JOB_TIMEOUT        = 30 s
  • < 80 %: normal.
  • ≥ 80 %: coalesce — one job per indicator_id pending. 100 reports → 1 recompute.
  • Queue full: shed enqueue, still 201. Report durably stored. Sweeper picks it up. Never reject a genuine report because our worker is behind.

Coalescing is the key insight: work is per indicator, not per report.

B.7 Ingestion pseudocode

async def post_report(payload):
    rl = rate_limit(...)
    if rl.exceeded: return 429(...)
    kind = KIND_MAP.get(payload["identifier_type"])
    canonical = canonicalise(kind, payload["identifier_value"]) if kind else None
    if canonical is None: return 400("invalid identifier")
    if payload["pincode"] not in AREA_TABLE: return 400("invalid area")
    occurred_at = parse_offset_datetime(payload["occurred_at"])
    if occurred_at is None or occurred_at > now()+5min: return 400("invalid occurred_at")

    async with db.transaction():
        indicator_id, was_new = await upsert_indicator(kind, canonical)
        inserted = await db.fetchval(INSERT_SQL, ..., ON CONFLICT DO NOTHING)
        if inserted is None:
            return 201(idempotent response, merged=True)
        if not queue.has_pending(indicator_id):
            queue.enqueue(indicator_id, "new_report")
    return 201(merged=not was_new)

C. Exact Time Windows

C.1 The rule

All windows use occurred_at. Never reported_at. reported_at used only for rate limiting and q_temporal.

C.2 Timezones

  • Parse offset → store as timestamptz (UTC).
  • Session SET TIME ZONE 'UTC'.
  • Never store local as timestamp without time zone.
  • Boundaries from DB now(), not app clock.
  • now() evaluated once per query.

C.3 Half-open intervals

Every window is [start, end). A report at exactly now−7d is outside.

C.4 The four windows

-- W1: seven-day rolling map
SELECT pincode, count(*), mode() WITHIN GROUP (ORDER BY scam_type)
FROM reports WHERE trust_state = 1
  AND occurred_at >= now() - interval '7 days' AND occurred_at < now()
GROUP BY pincode;

-- W2: seven-day baseline = [now-8d, now-1d) / 7
SELECT count(*)::float / 7 FROM reports
WHERE trust_state = 1 AND pincode = $1
  AND occurred_at >= now() - interval '8 days'
  AND occurred_at <  now() - interval '1 day';

-- W3: NEW_TYPE prior = [now-30d, now-1d)
SELECT 1 FROM reports
WHERE trust_state = 1 AND pincode = $1 AND scam_type = $2
  AND occurred_at >= now() - interval '30 days'
  AND occurred_at <  now() - interval '1 day'
LIMIT 1;

-- W4: 24-hour alert window
SELECT count(*) FROM reports
WHERE trust_state = 1 AND pincode = $1
  AND occurred_at >= now() - interval '24 hours' AND occurred_at < now();

W2 excludes the 24 h window from its own baseline. W3 excludes the 24 h window from the prior (self-disqualification).

G.5 Judge summary

Lookup does not count reports. It reads one precomputed row.

Report arrives → canonicalise → store → 201 in ~6 ms. Background worker recomputes that indicator's trust and writes the verdict into a single indicators row, pushes finished JSON to Redis.

Lookup: canonicalise, in-process cache, Redis, then one unique-index probe on a table with one row per phone number. O(1) in reports — query cost doesn't grow as the platform succeeds.

Internal budget ~16 ms at p95. The 500 ms target is dominated by network we don't control — that's why we designed for an order of magnitude of headroom.

All windows use occurred_at, compared in UTC against the database clock, half-open. reported_at never enters a window — that's what stops replay attacks.

Alerts read only trusted reports. No anti-abuse logic in the alert layer — the trust engine sets trust_state=1 for representatives, =2 for ignored. SPIKE needs 5 trusted reports and 2× the 7-day daily average; zero baseline means 2×0=0 vacuous and the floor does the work. NEW_TYPE compares 24h vs prior 30d, evaluation window excluded so a report can't disqualify its own alert.

2 · The Selected Algorithm

INPUT: reports for indicator I, now, cfg

1. GATE     If I ∈ VERIFIED_ALLOWLIST → VERIFIED_BUSINESS [ALLOWLISTED]
2. VALIDATE (no-op at read time — rejected rows absent from store)
3. WEIGH    For each report r:
              w_r = clip(q_note·q_type·q_evidence·q_temporal·rho, 0, 1)
4. CLUSTER  Union-Find: a~b iff a.rid_fp=b.rid_fp ∨ (a.net_fp=b.net_fp ∧ Δt≤cfg.net_window)
              v(C_i) = max_{r∈C_i} w_r
5. CAMPAIGN If k ≥ cfg.campaign_min_group, find 120-min window G:
              γ_note = fraction with Jaccard ≥ 0.70 partner
              γ_time = fraction in window
              γ_age  = fraction with < 3 prior reports
              γ      = 0.55·γ_note + 0.30·γ_time + 0.15·γ_age
              If γ_note ≥ cfg.gamma_note_min ∧ γ ≥ cfg.gamma_min:
                v(G) = max_{C_i∈G} v(C_i) · min(1, 1+0.1·log2|G|)
                E = Σ_{C_i∉G} v(C_i) + v(G)
              Else: E = Σ v(C_i)
              Otherwise: E = Σ v(C_i)
6. DISPUTE  D = cfg.D_open if open; cfg.D_upheld if upheld; else 0
7. POSTERIOR α = cfg.alpha0 + E; β = cfg.beta0 + D; S = α/(α+β)
8. STATE    c = k
              NO_REPORTS       if c == 0
              DISPUTED         elif challenge_open
              HIGH_CONFIDENCE  elif c ≥ cfg.hc_min_clusters ∧ S ≥ cfg.hc_min_score
              CORROBORATED     elif c ≥ cfg.corr_min_clusters ∧ S ≥ cfg.corr_min_score
              UNVERIFIED       else
              EXPIRED          if now-last_seen > cfg.expiry_days ∧ S < cfg.expiry_score_floor
9. VERDICT  KNOWN_SCAM iff state==HIGH_CONFIDENCE
                       ∧ c ≥ 3 ∧ ¬challenge ∧ ¬allowlisted
            else SUSPICIOUS if c ≥ 1
            else NO_REPORTS
10. DISPLAY If c < 3: mask. "Reported by {c} people near you".

Pure function of (reports, cfg, now). No random, no network, no wall clock.

def assess(indicator, now, cfg):
    if allowlisted(indicator): return VERIFIED_BUSINESS

    reports = sorted(store.reports(indicator), key=report_id)
    if not reports: return NO_REPORTS

    for r in reports:
        r.w = clip(note_q(r,cfg) * type_q(r,cfg) * evidence_q(r,cfg)
                   * temporal_q(r,now,cfg) * reputation(r,cfg), 0.0, 1.0)

    clusters = union_find(reports,
        same_rid     = lambda a,b: a.rid_fp == b.rid_fp,
        same_netbust = lambda a,b: a.net_fp == b.net_fp
                                    and abs(a.reported_at-b.reported_at) <= cfg.net_window)
    v = {cid: max(r.w for r in g) for cid,g in clusters.items()}

    E = sum(v.values())
    campaign = detect_campaign(clusters, reports, cfg)
    if campaign:
        v_G = max(v[c] for c in campaign) * min(1.0, 1+0.1*log2(len(campaign)))
        E = sum(val for c,val in v.items() if c not in campaign) + v_G

    D = (cfg.D_open   if indicator.challenge_status == "open"
         else cfg.D_upheld if indicator.challenge_status == "upheld"
         else 0.0)
    S = (cfg.alpha0 + E) / (cfg.alpha0 + cfg.beta0 + E + D)
    c = len(clusters)
    state, reason = classify(c, S, indicator, now, cfg)

    verdict = "KNOWN_SCAM" if state == "HIGH_CONFIDENCE" else "SUSPICIOUS"
    if indicator.challenge_status == "open": verdict = "SUSPICIOUS"; reason.append("CHALLENGE_OPEN")
    if c < 3:                                verdict = "SUSPICIOUS"; reason.append("BELOW_PRIVACY_FLOOR")
    if allowlisted(indicator):               verdict = "VERIFIED_BUSINESS"; reason.append("ALLOWLISTED")

    return Assessment(verdict=verdict, state=state, c=c, E=round(E,6), S=round(S,6),
        report_count=len(reports),
        first_seen=min(r.occurred_at for r in reports),
        last_seen=max(r.occurred_at for r in reports),
        display_value=mask(indicator, c), reason=reason)
def classify(c, S, indicator, now, cfg):
    if c == 0: return "NO_REPORTS", ["EMPTY"]
    if indicator.challenge_status == "open": return "DISPUTED", ["CHALLENGE_OPEN"]
    if now - indicator.last_seen > cfg.expiry_days and S < cfg.expiry_score_floor:
        return "EXPIRED", ["STALE_DECAY"]
    prev = indicator.previous_state
    if prev == "HIGH_CONFIDENCE" and S >= cfg.demote_hc_to_corr:
        return "HIGH_CONFIDENCE", ["HYSTERESIS_HOLD"]
    if prev == "CORROBORATED" and S >= cfg.demote_corr_to_unv and c >= cfg.corr_min_clusters:
        return "CORROBORATED", ["HYSTERESIS_HOLD"]
    if c >= cfg.hc_min_clusters and S >= cfg.hc_min_score:
        return "HIGH_CONFIDENCE", ["HIGH_CONFIDENCE"]
    if c >= cfg.corr_min_clusters and S >= cfg.corr_min_score:
        return "CORROBORATED", ["CORROBORATED_LOW"]
    return "UNVERIFIED", ["CLUSTER_SINGLE"]
def detect_campaign(clusters, reports, cfg):
    if len(clusters) < cfg.campaign_min_group: return None
    for window in sliding_windows(reports, minutes=120):
        ids = {cluster_of(r) for r in window}
        if len(ids) < cfg.campaign_min_group: continue
        γ_note = template_fraction(window, cfg.note_jaccard)
        γ_time = fraction(window, minutes=120)
        γ_age  = fraction(window, reporter_history_lt=3)
        γ      = 0.55*γ_note + 0.30*γ_time + 0.15*γ_age
        if γ_note >= cfg.gamma_note_min and γ >= cfg.gamma_min:
            return ids
    return None
